# Pinterest MCP Integration

A private MCP-compatible integration for accessing the repository owner's own Pinterest Business account through the official Pinterest API.

The integration is intended for personal/internal use by the account owner. Its purpose is to retrieve and, when explicitly requested, manage the owner's Pinterest boards and Pins through authorized Pinterest API access.
